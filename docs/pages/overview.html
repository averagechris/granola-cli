granola-cli overview

Read Granola notes from the terminal

granola-cli is a Rust command-line interface for Granola meeting notes, transcripts, summaries, folders, exports, and local cache workflows.

Install / downloadSource repository

At a glance

Notes and transcripts

List recent notes, fetch one note by ID or copied Granola URL, and request fields such as summary or transcript.

Local cache search

granola notes search searches the local note cache rather than the Granola API; sync first when you need transcript-backed searches.

Exports

Export one note or many notes as Markdown, JSON, JSONL, text, or transcript-focused output, with optional frontmatter and redaction.

Folders and views

List folder trees, filter note queries by folder, and save named local or API-backed views for repeated meeting queries.

Agent-friendly output

Use JSON output, field projection, digests, bounded context bundles, and JSONL batch retrieval for scripts and coding agents.

Credential handling

Store the Granola API key in the OS keyring with granola auth login, or pass a process-local key for automation.

Where data comes from

Authenticated commands call Granola's public API at https://public-api.granola.ai. Full-note reads can use a local non-secret cache, and cache-aware commands can write through to that cache unless disabled with --no-cache or --no-cache-write. Search views and granola notes search operate on locally synced cached notes.

Main workflows

01 Install and authenticate

Download a release or use Nix, then store an API key and validate access.

granola auth login --validate
  
granola-cli is local-first where it can be: API for source data, local cache for fast search and repeatable scripting.
