granola-cli example

A meeting-note workflow

This sanitized transcript shows the command shapes for listing recent meetings, selecting one note, reading its summary and transcript, and exporting Markdown.

Read the overview

Terminal transcript

# List recent meetings with machine-friendly fields.
$ granola notes list --since 7d --sort updated-at --order desc --fields notes.id,notes.title,notes.updated_at,count --output json-compact
{"count":3,"notes":[{"id":"not_weekly_platform_sync","title":"Weekly platform sync","updated_at":"2026-07-03T16:42:00Z"},{"id":"not_release_readiness","title":"Release readiness check","updated_at":"2026-07-02T21:05:00Z"},{"id":"not_design_review","title":"Search design review","updated_at":"2026-07-01T18:30:00Z"}]}

# Read the selected meeting's title and summary.
$ granola notes get not_weekly_platform_sync --fields title,summary --output list
title: Weekly platform sync
summary:
- Reviewed the status of the cache refresh work.
- Agreed to keep the next release small and verify docs before publishing.
- Follow-up: test transcript export against a recently synced note.

# Fetch only the transcript text, redacting attendee names if needed.
$ granola notes get not_weekly_platform_sync --fields transcript --redact attendees
[00:00:04] Speaker 1: Let's start with the cache refresh and release checklist.
[00:00:18] Speaker 2: The local search path is working; transcript search depends on notes synced with transcripts.
[00:00:41] Speaker 1: Good. Please export the final note and attach it to the release notes draft.
[00:01:03] Speaker 2: I'll generate Markdown with frontmatter and include the transcript.

# Save a Markdown copy for a release-note draft or agent context.
$ granola export note not_weekly_platform_sync --format markdown --include-transcript --frontmatter -o weekly-platform-sync.md
wrote weekly-platform-sync.md

What happened

List

notes list queried accessible notes from the Granola API and projected the response down to IDs, titles, timestamps, and a count.

Show

notes get accepted a Granola note ID. Requesting transcript fields fetches transcript data automatically when available.

Export

export note wrote a Markdown file using the same note selector, with transcript text and YAML frontmatter enabled.
